# 📊 Sales Analytics Dashboard

> Interactive sales analytics dashboard built with Python, Pandas, Plotly and Streamlit.

## 📌 Project Overview

Sales Analytics Dashboard — bu savdo ma'lumotlarini interaktiv tarzda tahlil qilish va vizuallashtirish uchun ishlab chiqilgan web dashboard.

Dashboard orqali foydalanuvchi savdo ko'rsatkichlarini turli sana, hudud, kategoriya va mahsulotlar bo'yicha filtrlashi hamda natijalarni grafiklar orqali ko'rishi mumkin.

Ushbu loyiha Data Analytics va Data Visualization ko'nikmalarini amaliy loyihada qo'llash maqsadida ishlab chiqilgan.

---

## 🚀 Features

- 💰 Umumiy sotuvni ko'rsatish
- 📈 Umumiy foydani hisoblash
- 📦 Sotilgan mahsulotlar miqdorini ko'rsatish
- 🧾 Buyurtmalar sonini hisoblash
- 📊 Foyda marjasini hisoblash
- 📈 Vaqt bo'yicha sotuvlar dinamikasi
- 🏆 Mahsulotlar bo'yicha sotuv tahlili
- 🌍 Hududlar bo'yicha sotuv tahlili
- 📦 Kategoriyalar bo'yicha Sales va Profit tahlili
- 🎛 Interaktiv filterlar
- ⬇️ Filtrlangan ma'lumotlarni CSV formatida yuklab olish
- 📋 Filtrlangan ma'lumotlarni jadval ko'rinishida ko'rish
